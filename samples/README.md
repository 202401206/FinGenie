# Sample files

Use synthetic CSV/XLSX fixtures for public development. Shared JSON examples are
in `contracts/examples/`; this directory is for future parser input files.

Do not commit real financial documents, names, account numbers, UPI identifiers or
transaction details. The PDF suggests real-bank samples, but any future private
samples must be collected with permission, sanitized and reviewed before sharing.
Local private samples may live in ignored `samples/private/`, or outside the repo.
Do not print their contents in logs. Assign a steward before collecting samples.
